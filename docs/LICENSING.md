# Licensing MIRA

## Current model

Since **v0.8.0**, the original MIRA source code is **source-available under
the PolyForm Noncommercial License 1.0.0**. It is intentionally readable,
modifiable and usable for noncommercial purposes, but it is not an OSI
Open Source license.

Commercial use requires a separate written license from Benoît Petit. This
includes, in particular:

- embedding MIRA in a paid product or service;
- offering MIRA as a hosted, managed or SaaS service;
- selling a redistribution, commercial integration or support bundle based on
  MIRA; and
- using MIRA or its derivatives as a commercial product without permission.

The exact permissions and obligations are defined by [`LICENSE`](../LICENSE).
This document explains the project policy; it does not replace the license
text.

## Why PolyForm Noncommercial?

The project wants to keep the code inspectable and useful to individuals,
researchers, educators, public-interest organisations and contributors while
retaining a clear commercial licensing path for the maintainer. PolyForm
Noncommercial grants use, modification and redistribution for permitted
noncommercial purposes, while reserving commercial use for a separate
agreement.

This choice necessarily means that MIRA must not be described as “OSI open
source”. The Open Source Definition requires permission to use software for
any field of endeavour, including commercial use. MIRA is better described as
**source-available, noncommercial**.

## Versioning and future changes

The maintainer may publish future MIRA versions under a different license or
offer a dual-licensing/commercial license. A license change applies to the
version released with that change; it does not retroactively remove rights
already granted for earlier versions.

Versions published before **v0.8.0** remain available under the historical MIT
terms in [`LICENSE-MIT`](../LICENSE-MIT).

## Boundaries

The MIRA name, SOUL name, logo and visual identity are separate from the
software license. See [`NOTICE.md`](../NOTICE.md) and
[`BRAND_POLICY.md`](../BRAND_POLICY.md). User memories, prompts and other data
processed by MIRA are not relicensed by this project.

Contributions must preserve their provenance and the project’s contribution
terms. See [`CONTRIBUTOR_ASSIGNMENT_TEMPLATE.md`](../CONTRIBUTOR_ASSIGNMENT_TEMPLATE.md).

This is a project policy summary, not legal advice. For a commercial
deployment or a contribution involving material third-party rights, obtain a
written agreement and professional legal advice.
